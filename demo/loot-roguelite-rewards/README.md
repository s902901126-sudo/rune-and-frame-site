# LR15 — Four Reward Draft | Browser-playable Godot 4 demo

This is the restricted, free, **interactive LR15 sample** from RUNE & FRAME Loot & Roguelite Rewards. It replaces the old LR05 showcase at **the same URL**, without changing any inbound links.

- Browser actions: select any of the four cards (Moon Relic, Vital Flask, Skill Points, Gold Pouch), change a selection, view each item's details, and confirm a reward.
- On initial load none is selected; after confirmation the simulated Host acknowledgement locks the choice.
- Host responses are **simulated**. No real inventory, gameplay account, save data, loot RNG or backend integration is present.
- Exported from native Godot 4.7.1. The Web PCK is publicly extractable; it contains only the isolated LR15 preview (one composition and 27 PNG resources), not the remaining commercial 19 layouts.
- The original LR05 version is preserved in Git commit history; the production backup is stored outside the public website.

**Product:** https://andy0327.itch.io/loot-roguelite-rewards

The demo is provided to let visitors experience the interface; it is not the complete commercial asset bundle or its license.
