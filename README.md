### Try before you buy

The **Dark Fantasy RPG UI Kit** and **LABGRID-100** have free downloadable examples on their itch.io listings. Follow the product links above to inspect each demo's contents, format, and license.

These are **art and interface asset packs**, not complete games. Godot support and engine compatibility vary by product; read each listing's current specifications and limitations.

## What is in this repository?

This repository contains the **public marketing website** and product information pages. It is **not** the source repository for the paid game asset packs. The commercial asset licenses on itch.io do not automatically grant permission to redistribute the underlying SVG, PNG, or project files.

**Promotional videos:** [RUNE & FRAME brand trailer](https://youtu.be/TDL-W3ECDE8) · [LABGRID-100](https://youtu.be/tesOslS76bw) · [Fantasy Heroines](https://youtu.be/TfYPxeI3Cck).

The video sequences may include AI-assisted animation and promotional characters. Refer to the product pages for the actual downloadable contents.
