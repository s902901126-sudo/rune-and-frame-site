# LR05 — Browser-Playable Godot 4 Demo

This public folder hosts the **restricted, free-sample-only LR05 Reward Selection UI**, exported from Godot 4.7.1. It is genuine Godot HTML/WASM/PCK, not a GIF, mock HTML interaction, or the full commercial 20-screen product.

- Browser test actions: select a reward, confirm a claim, and see the claimed/locked states.
- Demonstration Host responses are simulated; gameplay inventory, save files and loot RNG are not supplied.
- The Web PCK is publicly extractable; only the existing LR05 free-sample scope is published, never the other 19 UI projects.
