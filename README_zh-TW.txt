發佈方式（GitHub Pages）：
1. 登入 https://github.com/new
2. Owner 選 s902901126-sudo，Repository name 輸入 rune-and-frame-site。
3. 設成 Public，並建立 repository（預先建立 README 可省略）。
4. 點 Add file → Upload files；將本 ZIP 解壓縮後的「內容」，包括 index.html、style.css、robots.txt、sitemap.xml、favicon.svg、.nojekyll、products/ 資料夾上傳到「repository 根目錄」。注意不是把 ZIP 直接上傳當網站。
5. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save。
6. 開啟 GitHub Pages 預期網址確認首頁與三個商品詳細頁。發佈後可用 Google Search Console / Bing Webmaster Tools 設定索引。

重要：如果改用其他 GitHub 帳號或 repository 名稱，先同步修改 4 個 HTML 裡的 canonical / og:url、robots.txt、sitemap.xml 中的網址。

資料依據：三個已公開的 itch.io 商品頁與可公開存取的官方商品封面。
